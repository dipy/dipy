# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of DIPY. We
recommend always using the most recent release.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

Instead, report them privately using GitHub's
[private vulnerability reporting](https://github.com/dipy/dipy/security/advisories/new)
feature on this repository.

Please include as much of the following as you can:

- A description of the issue and its potential impact
- The affected DIPY version(s) and environment (OS, Python version)
- Steps to reproduce, or a minimal proof of concept
- Any suggested fix or mitigation, if known

## What to Expect

- We will acknowledge receipt of your report as soon as possible.
- We will investigate, keep you informed of our progress, and may ask for
  additional details.
- Once a fix is available, we will publish a security advisory and credit you
  for the discovery, unless you prefer to remain anonymous.

DIPY is maintained by volunteers, so response times may vary. Thank you for
helping keep DIPY and its users safe.
